description: Compare saved BranchForge runs while accounting for problem, provider and budget differences.
---

Use compare_runs for two to ten IDs. Check problem/test fingerprints, actual provider, model, algorithm and limits before comparing rewards. Distinguish fake demonstration from real model evidence, unknown usage from zero, and partial results from completed runs. Do not infer causal quality improvements from unmatched runs.

Use the BranchForge MCP tools for scheduling and enforcement; never reproduce search policies in prose or execute candidate code on the host. Jobs belong to the MCP process and stop when it exits.
